## Resolved issues

| Area | Observed failure or weakness | Change and evidence |
| --- | --- | --- |
| Atomic state | Checkpoint writes swallowed I/O failures; predictable `.tmp` files collided between writers and could follow existing symlinks | Unique private temporary files, fsync/replace, POSIX directory fsync, propagated errors; failed-write and concurrent-writer tests |
| Corrupt state | Oversized/malformed checkpoints and corrupt manifests could become empty state and later overwrite valid data | Missing files alone initialize empty; schema/size/corruption failures stop the operation; corruption-preservation tests |
| Manifest boundary | Unvalidated store names could construct paths outside the manifest directory; non-POSIX locking silently disappeared | Restricted store names and portable file locks; invalid-name and concurrent-update tests |
| Corpus synchronization | Deleted PDFs stayed in the master checkpoint; unchanged, empty, and failed processing all used the same empty-list result | Staged complete-corpus sync, explicit unchanged result, visible parse failure, successful-empty removal; real PDF/config-change/deletion tests |
| Chunk size | Entire pages went to embeddings/reranking, allowing oversized input and truncation loss | Bounded overlapping page chunks, stable IDs, extraction-setting fingerprint, PDF byte/page limits |
| Enrichment | Failed API calls were cached as completed work; enrichment mutated raw chunk objects | Retryable uncached failures, separate enriched copies, source-text validation, offline cache selection; retry and invalidation tests |
| Lexical index | All-empty token corpora could crash BM25 construction | Skip empty-token documents and maintain the corresponding ID map |
| Dense index | No-ingestion early return skipped deletions; stale chunks were deleted before replacement success; hashes ignored extraction/enrichment changes | Always handle deleted documents, upsert-before-prune, richer fingerprints, per-document commits, explicit failures; mocked failure tests and real persistent Chroma tests |
| Cleanup | Deleting rows while advancing offsets skipped later orphans | Snapshot IDs to disk before bounded deletion; tests and benchmarks use truly mutating collections |
| Graph state | Changed/deleted PDFs retained prior graph relationships; reset deleted the directory but could retain the external manifest and skip ingestion | Package-level isolated graph generations; completion checks and flush before atomic pointer publication; failed/changed/empty graph tests |
| Async execution | Synchronous retrieval, reranking, generation, and HTTP calls blocked the event loop | Thread offloading, native async adapters, stage timeouts, concurrent retrieval channels; heartbeat test |
| Retrieval failure | Dense failure prevented BM25 fallback; result order and source correspondence were implicit | Independent fallbacks, explicit returned-ID mapping, aligned citations, bounded evidence, structured error state |
| Ranking/evaluation | Tie order was unstable; non-finite scores could rank highly; duplicate IDs inflated fusion; question/reference lengths were unchecked | Deterministic finite top-k, deduplicated fusion, input validation, macro retrieval quality metrics |
| Generation boundary | Retrieved instructions and user requests shared one undifferentiated prompt; vendor exception text could leak into answers | System instruction plus JSON evidence, context/output limits, no generation without evidence, redacted errors. Prompt injection remains an LLM limitation |
| Notebook setup | Old pinned dependencies and mutable downloaded shell execution | Modern optional dependency extra, checked resolution/API surfaces, removed remote shell installation, explicit enrichment opt-in |
| Packaging | Installed-wheel smoke delegated to repository-only scripts | Direct package smoke/ingestion commands; isolated installed-wheel checks |
| Automation | Weekly Dependabot version updates created the reported branches | Set pip and Actions version-update PR limits to zero; keep read-only, pinned CI with timeouts/concurrency and Python matrix |
| Benchmark evidence | Deletion mocks did not actually remove rows; single timings lacked correctness assertions | Mutable simulator, reference ranking checks, exact orphan-count assertions, warmup/repeats, median/p95 and memory-scope disclosure |

The branch metadata identified Dependabot, not a branch-writing CI job. Repository-level automatic security updates are separate from version updates. ## Remaining upstream advisories and deployment limits

The optional resolved stack still reports six unique advisory IDs across three packages, with no fixed version published by the advisory source:

| Package | Advisory IDs | Affected boundary and handling |
| --- | --- | --- |
| ChromaDB 1.5.9 | `PYSEC-2026-311`, `PYSEC-2026-3814`, `PYSEC-2026-3815`, `PYSEC-2026-3813` | Server-side model-code loading and authorization/tenant isolation. The notebook uses embedded `PersistentClient`, a configured embedding model, and no Chroma HTTP server. Do not expose an untrusted or multi-tenant Chroma server or enable remote model code. This local scope restriction is not an upstream patch |
| Ragas 0.4.3 | `PYSEC-2026-3046` | Multimodal metric URL/file processing can perform SSRF. The notebook chooses text metrics and accepts no URL-based multimodal evaluation input. Do not enable affected multimodal paths with untrusted data |
| diskcache 5.6.3 (transitive) | `PYSEC-2026-2447` | Pickle-backed cache files are unsafe when an attacker can modify the cache directory. Keep runtime/cache directories private and do not load externally supplied caches. No safe upstream release was available |

The audit output can contain duplicate records for the same advisory; the table deduplicates IDs rather than hiding affected packages. Other obsolete dependency advisories were addressed by upgrading floors/compatible optional ranges, including pypdf, requests, datasets, and the LangChain/OpenAI stack.

Additional limits:

- Full live Groq/Ollama/LightRAG/model/Ragas execution and evaluation on a representative corpus remain unverified because the required services/credentials/data were absent. Adapter mocks, wheel/API inspection, resolution, and local Chroma tests have narrower coverage.
- Chroma writes are not multi-record transactions. Partial writes require retry and readers need an ingestion pause for consistent snapshots.
- Graph rebuilds increase ingestion cost and retain older generations. They favor consistency over append-only speed; prune old generations only after stopping readers.
- Synchronous worker cancellation cannot stop an in-flight call. Bound the injected network client's own timeout.
- PDF byte/page limits do not sandbox parser CPU/memory use. For untrusted ingestion, isolate parsing in resource-limited processes before adding an exposed service.
- The master JSON checkpoint and BM25 index still scale with corpus size in memory. A database/sharded index is needed beyond the configured budget.
- Prompt structure and citations improve evidence handling, but do not guarantee factual answers or eliminate adversarial document instructions.
