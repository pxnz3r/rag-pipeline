# Follow-up architecture audit — 0.3

Baseline is the merged 0.2 commit `e217ae819ec40c834205a7344f6c6c91af8193f7`. The earlier [audit](AUDIT-2026-10-02.md) identified split-state transactions, in-memory corpus growth, retained graph generations, unsafe optional dependencies and absent domain-quality evidence.

Resolved structurally: one SQLite transaction owns source text, metadata, FTS and vectors; readers have WAL snapshots; parser/embedding failures roll back the whole corpus update. Disk-backed lexical retrieval and batched exact dense scans replace whole-corpus Python BM25 storage. Unique relative source IDs avoid basename collisions. Resource-capped PDF parsing is a disposable process. Labeled account rows, scoped retrieval, exact evidence and explicit Decimal calculations replace unchecked enrichment and numerical generation.

The declared runtime no longer contains Chroma, Ragas, LightRAG, LangChain, diskcache, PyTorch, requests or rank-bm25. Their six previously reported no-fix advisory paths are removed rather than suppressed. Optional models use immutable tokenizer/ONNX revisions and standard CPU inference. This does not assert those upstream packages were repaired. Previously installed old dependencies remain installed until users create a fresh environment; use the migration guide.

Validation: real storage/extraction tests, corruption/rollback/filter/model/citation/numeric boundaries; Python 3.10/3.12; pinned CPU model interoperability; resolved dependency audits; installed wheel/sdist checks; public independently annotated FinQA/CUAD subsets and synthetic scale measurements. Exact results and reproduction are in [TESTING](TESTING.md) and the benchmark artifact. This is a direct engineering review, not a registered formal Codex Security scan.

Remaining limits: private single-user use only (no tenancy/auth service); metadata/operand meaning is user supplied; quote validation does not prove entailment; document prompt injection is not fully eliminated; scanned PDFs need OCR; complex PDF tables may be misordered; cross-page dependencies may require further retrieval; exact dense scans scale linearly; model truncation can omit context; reranking is expensive and domain dependent. No representative private financial/legal book corpus or live hosted generation endpoint was available. Public retrieval proxies do not establish world-leading or production answer accuracy. No-answer calibration beyond the small canary remains future evaluation work.

Dependabot version branches are disabled in source config. The separate owner-only automatic security-update setting remains inaccessible/unverified; CI does not have write permissions and never creates branches.
